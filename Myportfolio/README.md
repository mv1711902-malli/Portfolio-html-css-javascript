# 🌐 Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website developed using **HTML, CSS, and JavaScript**. The website showcases my personal information, technical skills, projects, educational background, and contact details.

The main objective of this project is to create a professional online presence and demonstrate my frontend web development skills.

## 🚀 Technologies Used

- **HTML5** – For creating the website structure.
- **CSS3** – For styling, layouts, animations, and responsive design.
- **JavaScript** – For adding interactive functionality and dynamic features.

## ✨ Features

- Modern and clean user interface.
- Home section with personal introduction.
- About Me section.
- Technical Skills section.
- Projects showcase.
- Education details.
- Contact information.
- Responsive design for different screen sizes.
- Interactive navigation using JavaScript.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript, and image files are in their correct locations.
4. Open `index.html` in your browser.
5. Explore the portfolio website.
